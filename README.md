# TermoLab Virtual: Simulador Cinético de Calor Específico

Un laboratorio virtual interactivo diseñado para el estudio y visualización de la termodinámica fundamental, centrado en el calor específico (c), el calor latente (L) y la transición de fase a nivel cinético-molecular.

---

## Características Principales

- Simulación Cinético-Molecular en Vivo: Animación gráfica en canvas HTML5 que modela el grado de agitación molecular y el estado de la materia (sólido, líquido o gas) según la temperatura actual.
- Amplia Base de Datos Termodinámica: Incluye sustancias como Agua, Aluminio, Cobre, Hierro, Oro, Alcohol Etílico y Plomo con sus respectivos calores específicos y temperaturas de cambio de fase.
- Cálculo Termodinámico Completo:
  - Calor sensible: Qs = m * c * Delta T
  - Calor latente de fusión/vaporización: Ql = m * L
- Conversión Automática de Unidades: Desglose en tiempo real de energía (cal, kcal, J), masa (g, kg) y diferencia de temperatura (Delta T en °C y K).
- Interfaz Adaptable: Construida con Tailwind CSS en estilo de panel científico con modo oscuro.

---

## Fundamento Teórico

El simulador se basa en los modelos fundamentales de transferencia de calor:

1. Calor Sensible (Qs): Cantidad de energía absorbida o cedida por una sustancia que produce una variación de temperatura sin alterar su estado físico.
   Qs = m * c * (Tf - Ti)

2. Calor Latente (Ql): Energía transferida durante un cambio de fase a temperatura constante.
   Ql = m * L

3. Energía Total (QT): Suma del calor sensible y los calores latentes requeridos durante las transiciones de fase alcanzadas en el intervalo de temperatura.

## Instalación y Uso Local

No se requieren dependencias externas ni compilación previa.

1. Clona este repositorio:
   git clone https://github.com/tu-usuario/termolab-virtual.git

2. Abre el archivo index.html en cualquier navegador web moderno (Chrome, Edge, Firefox, Safari).

## Despliegue en GitHub Pages

Este proyecto es totalmente estático y compatible con GitHub Pages:

1. Ve a los Settings del repositorio.
2. Navega a la sección Pages en la barra lateral.
3. Selecciona la rama main en la opción Branch y guarda.
4. El simulador estará disponible públicamente en pocos minutos.
